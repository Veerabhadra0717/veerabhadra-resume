# Veerabhadra R – Portfolio

Live address: https://veerabhadra-resume.vercel.app/

## Run on your computer
    npm start
Open http://localhost:3000
(node_modules is included. If you delete it, run `npm install` once.)

## Put it online
Upload everything EXCEPT node_modules to GitHub.
On GitHub you should see: public/, package.json, server.js, vercel.json
Vercel serves the files inside the "public" folder.
